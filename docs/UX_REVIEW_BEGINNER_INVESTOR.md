# KOSPI200 AI 랭킹 — 초보 투자자 관점 UX 전면 검토

> **목표**: "주식을 잘 모르는 사람이 이 사이트를 보고 투자에 도움을 받을 수 있는가?"
> **검토일**: 2026-03-11
> **검토 범위**: 프론트엔드 5페이지 + 백엔드 16개 API + 데이터 모델 전체

---

## 1. 핵심 진단: 현재 사이트는 "개발자/퀀트용"이지 "초보자용"이 아니다

| 문제 영역 | 현재 상태 | 초보자 반응 예상 |
|-----------|----------|----------------|
| 진입 경험 | 숫자 나열형 랭킹 테이블 | "이 숫자가 뭔데? 뭘 해야 하지?" |
| 용어 | Sharpe, MDD, IC, CAGR, phase | "무슨 뜻인지 모르겠음" |
| 행동 유도 | 없음 (정보만 나열) | "그래서 어떻게 하라는 거야?" |
| 리스크 경고 | 면책 문구 없음 | 법적/윤리적 문제 |
| 맥락 설명 | 없음 | "AI가 왜 이 종목을 골랐는지 모르겠음" |
| 비교 기준 | 벤치마크만 존재 | "다른 종목이랑 비교는?" |
| 시간 안내 | 장기/단기만 표시 | "나는 3개월 투자하려는데 뭘 봐야 하지?" |

## 2. 페이지별 상세 검토 + 수정안

### 2-1. 랭킹 페이지 (메인, `/`)

#### 현재 상태
- TOP 3 카드 + 필터(단기/장기, 날짜, 검색) + 테이블/카드 리스트
- 카테고리 배지 7개 + 한줄 요약 + AI 등급

#### 문제점

| # | 문제 | 심각도 | 설명 |
|---|------|--------|------|
| R1 | **첫 방문자 가이드 부재** | 높음 | 사이트에 처음 온 사람이 "이게 뭐하는 사이트인지" 파악할 수 없음. 히어로 섹션이나 온보딩이 없다 |
| R2 | **장기/단기 의미 불명확** | 높음 | "단기 20일", "장기 120일"만 표시. 초보자는 자신이 어떤 탭을 봐야 하는지 모름 |
| R3 | **순위의 의미 부재** | 중간 | "#1"이 좋다는 건 알겠지만, "200개 중 1위가 실제로 뭘 뜻하는지" 설명이 없음 |
| R4 | **카테고리 점수 해석 불가** | 중간 | 상승세 72, 안전도 35 → "72가 좋은 건지, 35면 위험한 건지" 기준이 없음 |
| R5 | **TOP 3의 투자 맥락 부재** | 중간 | 메달만 보여줄 뿐 "왜 이 종목이 좋은지" 1-2문장 설명이 부족 |
| R6 | **면책/경고 문구 없음** | 높음 | "투자 손실은 본인 책임"이라는 법적 면책이 전혀 없음 |

#### 수정안

| # | 수정 내용 | 우선순위 |
|---|----------|---------|
| R1-fix | **히어로 배너** 추가: "AI가 매일 분석하는 KOSPI200 종목 추천 — 200개 종목을 7가지 관점으로 평가합니다" + 간단 도식(데이터→AI→순위) | P0 |
| R2-fix | 탭에 **가이드 툴팁** 추가: "단기(20일): 빠른 매매 스타일에 적합 / 장기(120일): 3~6개월 보유에 적합. 처음이라면 장기를 추천합니다" | P0 |
| R3-fix | 순위 옆 **해석 텍스트**: "상위 5% — AI가 매우 유망하다고 판단" / "상위 25%" / "중간" / "하위 25%" | P1 |
| R4-fix | 카테고리 배지에 **호버 시 설명**: "상승세 72/100 — 최근 주가가 꾸준히 오르고 있어요" | P1 |
| R5-fix | TOP 3 카드에 **AI 한줄 요약** 강화: 현재 기능 합성 문장을 더 구체적으로. "삼성전자는 최근 3개월 상승률이 전체 종목 중 상위 5%이며, 뉴스 반응도 긍정적입니다" | P1 |
| R6-fix | **푸터 면책 고정**: "본 서비스는 투자 참고용이며, 투자 판단의 책임은 이용자 본인에게 있습니다. AI 분석은 과거 데이터 기반이며 미래 수익을 보장하지 않습니다." | P0 |

### 2-2. 종목 상세 페이지 (`/rankings/:ticker`)

#### 현재 상태
- AI 점수/등급 + TOP 3 피처 태그 + 레이더 차트 + 카테고리 바 + 점수 추이 + AI 분석 리포트

#### 문제점

| # | 문제 | 심각도 | 설명 |
|---|------|--------|------|
| S1 | **피처 이름이 영어** | 높음 | `momentum_3m`, `roe`, `volatility_60d` → 초보자 해독 불가 |
| S2 | **레이더 차트 해석 안내 없음** | 중간 | 7축 레이더를 처음 보는 사람은 "클수록 좋은 건지" 모름 |
| S3 | **"이 종목을 어떻게 활용하라"는 가이드 없음** | 높음 | 정보만 나열. "그래서 어쩌라는 거야?" 상태 |
| S4 | **동종업종/유사종목 비교 없음** | 중간 | 삼성전자가 좋은지 SK하이닉스랑 비교해야 알 수 있는데, 단독 뷰만 존재 |
| S5 | **점수 추이 맥락 부재** | 낮음 | "최근 30일 추이"만 보여줌. 급등/급락 이유 설명 없음 |
| S6 | **AI 분석이 버튼 클릭 후 로딩** | 낮음 | 핵심 정보인데 숨겨져 있음. 기본 노출이 더 좋음 |
| S7 | **실제 주가 정보 없음** | 높음 | 현재가, 등락률, 시가총액 등 기본 정보가 전혀 없어서 "이 종목이 얼마짜리 주식인지" 알 수 없음 |

#### 수정안

| # | 수정 내용 | 우선순위 |
|---|----------|---------|
| S1-fix | **피처 한글 매핑** 강화: `momentum_3m` → "3개월 상승률", `roe` → "자기자본수익률(ROE)", `volatility_60d` → "60일 변동성" + 각각에 한줄 설명 툴팁 | P0 |
| S2-fix | 레이더 차트 상단에 **안내 문구**: "바깥쪽일수록 해당 영역이 강합니다. 균형 잡힌 모양이 이상적입니다" | P1 |
| S3-fix | **투자 포인트 요약 카드** 추가 (상단): "이 종목은 [상승세]가 강하지만 [안전도]는 낮습니다. 공격적 투자 성향에 적합합니다" (카테고리 점수 기반 자동 생성) | P0 |
| S4-fix | **유사 종목 추천** 섹션: 같은 업종 or 비슷한 카테고리 프로필을 가진 종목 3개 노출 (DB에 데이터 있음) | P2 |
| S5-fix | 추이 차트에 **이벤트 마커**: 큰 변동이 있는 날에 점 표시 + "뉴스 감성 급변" 등 라벨 | P2 |
| S6-fix | AI 분석을 **기본 노출** (접힌 상태가 아니라 열린 상태로). 로딩은 페이지 진입 시 자동 시작 | P1 |
| S7-fix | **기본 주가 정보 카드** 추가: 현재가, 전일대비, 시가총액. OHLCV 데이터는 DB에 이미 있음 (`panel_merged_daily`의 close, volume 등) | P0 |

### 2-3. 백테스트 페이지 (`/backtest`)

#### 현재 상태
- 4개 전략 카드 + phase 탭(검증/학습) + 핵심 3지표 카드 + 에쿼티 커브 + 상세 테이블

#### 문제점

| # | 문제 | 심각도 | 설명 |
|---|------|--------|------|
| B1 | **"백테스트"란 용어 자체가 난해** | 높음 | 초보자는 "백테스트"가 뭔지 모름 |
| B2 | **4개 전략 차이 설명 없음** | 높음 | bt120_long, bt120_ens, bt20_short, bt20_ens → "뭐가 다른 거지?" |
| B3 | **검증/학습 기간 구분 불명** | 높음 | "holdout"과 "dev"의 의미를 아는 사람이 극소수 |
| B4 | **CAGR을 "누적 수익률"로 오표기** | 중간 | CAGR은 연 복합 수익률이지 누적이 아님. 100만→124만 계산도 잘못됨 (CAGR×100+100이 누적수익이 아님) |
| B5 | **Sharpe, IC, Calmar 설명 부족** | 중간 | 상세 테이블의 지표가 "설명" 컬럼이 있지만 너무 짧아서 초보자에겐 여전히 불충분 |
| B6 | **그래프 조작법이 비직관적** | 낮음 | 마우스 휠 줌은 좋지만, 모바일에서는 불가. 또한 "Shift+휠"은 대부분 모름 |
| B7 | **"이 전략을 따라 투자하려면?" 가이드 없음** | 높음 | 과거 성과만 보여주고, 실제 행동 연결이 없음 |
| B8 | **누적 수익률 계산이 부정확** | 중간 | `(1 + cagr) * 100` 은 CAGR 1년치만 반영. 실제 누적수익(`net_total_return`)을 써야 정확 |

#### 수정안

| # | 수정 내용 | 우선순위 |
|---|----------|---------|
| B1-fix | 페이지 제목 변경: "백테스트 성과" → **"과거 성과 검증 — AI가 추천한 종목으로 투자했다면?"** + 상단 설명: "과거 10년간 AI 추천을 따랐을 때의 가상 투자 성과입니다. 실제 투자와 다를 수 있습니다." | P0 |
| B2-fix | 각 전략 카드에 **한줄 설명** 추가: "Long 120일 → 상위 10종목을 사서 120일 보유", "Short 20일 → 하위 10종목을 매도하여 20일 보유", "Ensemble → 4개 AI 모델 평균" | P0 |
| B3-fix | phase 탭 **리네이밍**: "검증 기간(2023~)" → "실전 테스트 (AI가 못 본 데이터)", "학습 기간(~2022)" → "연습 기간 (AI가 학습한 데이터)". 툴팁: "실전 테스트 결과가 더 신뢰도 높습니다" | P0 |
| B4-fix | "누적 수익률" → **"연평균 수익률(CAGR)"**로 정정. 별도로 `net_total_return` 사용한 **"총 누적 수익률"** 카드 추가 | P1 |
| B5-fix | 상세 테이블의 각 지표에 **확장 설명 아코디언**: "Sharpe — 위험 1 단위당 얼마나 벌었는지. 1.0 이상이면 우수, 0.5 이하면 부족" | P1 |
| B6-fix | **드래그 패닝** 추가 + 모바일용 **핀치 줌** + 상단에 기간 프리셋 버튼: "전체 / 최근 1년 / 최근 3년 / 최근 5년" | P1 |
| B7-fix | **행동 가이드 카드**: "이 전략을 활용하는 방법: 1) 랭킹 페이지에서 오늘의 TOP 10 확인 2) 120일(약 6개월) 보유 3) 리밸런싱일에 교체. 과거 성과가 미래를 보장하지 않습니다." | P0 |
| B8-fix | `net_total_return` 활용: "10년간 총 수익 +58%" / CAGR: "연평균 +4.7%" 분리 표시 | P1 |

## 4. 신규 기능 제안

### 4-1. "나의 투자 성향 진단" (P1)
- 3~5개 질문: 투자 기간, 리스크 허용도, 관심 업종
- 결과에 따라 "장기/단기", "공격적/안정적" 추천 → 적합한 전략+필터 자동 설정
- 재방문 시 기억 (localStorage)

### 4-2. "시장 현황 대시보드" (P1)
- KOSPI200 지수 + VIX + 원/달러 + 유가
- 현재 시장 regime (상승/횡보/하락)
- "AI 추천 신뢰도": 최근 IC/Rank IC 기반 "이번 달 AI 적중률 62%"

### 4-3. "종목 비교" (P2)
- 2~4개 종목 선택 → 레이더 오버레이 + 카테고리 비교 테이블
- "삼성전자 vs SK하이닉스: 수익성은 삼성이 우위, 모멘텀은 SK가 우위"

### 4-4. "투자 용어 사전" (P1)
- 사이트 내 모든 전문 용어를 모아둔 페이지
- 각 페이지에서 용어 클릭 시 팝오버로 연결
- 예: "MDD" 클릭 → "최대 낙폭: 투자 기간 중 최고점에서 최저점까지 떨어진 폭. 예) MDD -15%는 100만원이 85만원까지 빠졌다는 뜻"

### 4-5. "알림 구독" (P3)
- "삼성전자가 TOP 10 진입 시 알림"
- "내 관심 종목 순위 변동 알림"
- 이메일 or 텔레그램 봇

## 6. 구현 시 핵심 원칙

1. **모든 숫자에 맥락을**: 72점 → "72/100 (상위 15%)"
2. **모든 전문 용어에 한글 설명을**: Sharpe → "위험 대비 수익 효율"
3. **모든 차트에 읽는 법을**: "위로 갈수록 수익이 높습니다"
4. **모든 정보에 "그래서?"를**: 데이터 → 해석 → 행동 제안
5. **면책은 반드시**: 투자 권유가 아님을 명시
6. **점진적 공개**: 기본은 단순, "더보기"로 상세 → 초보자와 고급 사용자 모두 만족

## 8. 결론

현재 시스템은 **데이터와 기술 인프라는 충분**하지만, **초보 투자자를 위한 "번역 레이어"가 부재**하다.
핵심은 코드를 새로 짜는 게 아니라, **기존 데이터 위에 맥락·해석·가이드를 덮는 것**이다.

P0 작업만 완료해도 "숫자 나열 사이트"에서 "투자 도우미 사이트"로 전환 가능하다.
